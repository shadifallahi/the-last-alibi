# 🔎 The Last Alibi

**The Last Alibi** is a terminal-based detective mystery game developed in Python. Players take on the role of a detective investigating the mysterious death of Edward Blackwood.

Explore the crime scene, interview suspects, collect clues, analyze evidence, uncover contradictions, and identify the murderer.

## 🎮 Game Features

- **Crime Scene Investigation:** Explore Edward Blackwood's bedroom and discover hidden clues.
- **Suspect Interviews:** Interview three suspects and investigate their statements.
- **Detective Notebook:** Keep track of discovered clues, interviewed suspects, and analyzed evidence.
- **Evidence Analysis:** Examine photographs, burned letters, suspicious window scratches, and other evidence.
- **Contradiction Detection:** Compare suspect statements with discovered evidence to uncover inconsistencies.
- **Final Accusation:** Use the collected evidence to identify the murderer and solve the case.

## 🛠️ Technologies Used

- Python 3
- Dictionaries and Lists
- Functions
- Loops and Conditional Statements

## 🚀 Getting Started

### Prerequisites

Make sure Python 3 is installed on your computer.

Check your Python version:

```bash
python3 --version
```

### Installation

1. Clone the repository:

```bash
git clone https://github.com/shadifallahi/the-last-alibi.git
```

2. Navigate to the project directory:

```bash
cd the-last-alibi
```

3. Run the game:

```bash
python3 main.py
```

## 🕵️ How to Play

1. Start the game and enter the main menu.
2. Investigate Edward Blackwood's bedroom to discover clues.
3. Interview the three suspects and examine their statements.
4. Analyze the collected evidence to uncover important details.
5. Review your detective notebook.
6. Make your final accusation and solve the mystery!
